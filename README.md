# FinSight - CA Practice & Compliance Management

An intelligent practice and compliance management system designed for chartered accountants and tax professionals.

## Contributors
- Kanishka Gianchandani (@kanishka747)
- Arya Jaiswal (@jais-create)

## Tech Stack
- Frontend: React 19, TypeScript, Tailwind CSS, Vite
- Backend: Express, Google Gemini API

## Setup
```bash
npm install
cp .env.example .env
npm run dev
```
